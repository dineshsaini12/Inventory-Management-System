# Inventory Management System

A full-stack Inventory Management System developed using **React, Node.js, Express.js, and MySQL**. The system helps manage products, inventory/stock, suppliers, customers, and purchase orders through a responsive and user-friendly dashboard.

### Tech Stack

* **Frontend:** React, Tailwind CSS, Axios
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Icons:** Lucide React

### Main Features

* User authentication and role-based access
* Product management
* Stock management
* Supplier management
* Customer management
* Purchase order management
* Inventory tracking
* Responsive dashboard
* REST API integration
